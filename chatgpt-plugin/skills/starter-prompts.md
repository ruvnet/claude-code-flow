# RuFlo Federation starter prompts

## Recommended store prompts

1. Show me the latest RuFlo swarm activity and summarize what each agent is working on.
2. List the available RuFlo channels and read the most recent announcements.
3. Check current work claims and identify resources that are free for another agent.

These prompts are intentionally observational. They demonstrate useful coordination workflows while leaving claims, releases, joins, and publishing under explicit user control.

## Optional action prompt

Draft a concise status update for the RuFlo swarm and show me exactly what will be published before sending it.

Use this optional prompt only if a future listing allows more than three starters or emphasizes publishing. The `publish-ruflo-update` skill requires confirmation before the irreversible gateway-signed event is sent.
